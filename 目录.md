# 课程目录（快速导航）

> 本页独立于 [README](./README.md)：把 **98 个练习** 摊平列出，一点即可进入对应 `教学.md` / 源码目录。
>
> 建议学习顺序：从上到下。每题闭环：读教学 → 改 `src` → `cargo test -p <crate>`。

## 使用说明

| 列 | 含义 |
| --- | --- |
| 练习 | 进入练习目录 |
| 教学 | 打开该题 `教学.md`（怎么改、怎么跑） |
| 源码 | 打开 `src/lib.rs` 或入口文件 |
| 教程 | 对应 `book` 章节 |
| 运行 | 复制到终端执行 |
