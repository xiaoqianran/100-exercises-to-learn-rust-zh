# 语法

Rust 的函数看起来大致如下：

```rust
fn 函数名(参数名: 参数类型) -> 返回类型 {
    // 函数体
}
```

## 函数签名

`fn` 后面的部分称为**函数签名**：名字、参数与返回类型。

示例：

```rust
fn add(a: u32, b: u32) -> u32 {
    a + b
}
```

- 两个参数 `a`、`b`，类型都是 `u32`
- 返回类型是 `u32`
- 函数体是表达式 `a + b`（注意：最后一行表达式可作为返回值，通常不必写 `return`）

## 类型标注

Rust 是**静态类型**语言：每个值在编译期都有确定类型。  
函数边界上的类型通常需要写清楚，便于编译器检查，也便于阅读。

## 编译器是你的伙伴

若签名不完整（例如参数没有类型），编译会失败并给出错误信息。  
**请养成阅读报错的习惯**——它常常直接告诉你缺了什么。
