# 类型（一）：整数

在「语法」一节中，`compute` 的参数类型是 `u32`。下面拆开讲这意味着什么。

## 原始类型

`u32` 是 Rust 的**原始类型**之一：语言内建，不由其他类型组合定义。你可以用它们组合出更复杂的类型。

## 整数

`u32` 是**无符号 32 位整数**。

- **无符号 / 有符号**：`u*` 只能表示 ≥0；`i*` 可正可负。
- **位宽**：`8/16/32/64/128`。位宽越大，可表示范围越大。

| 位宽 | 有符号 | 无符号 |
| --- | --- | --- |
| 8 | `i8` | `u8` |
| 16 | `i16` | `u16` |
| 32 | `i32` | `u32` |
| 64 | `i64` | `u64` |
| 128 | `i128` | `u128` |

## 字面量

`42` 是整数字面量。无足够上下文时，编译器常把整数默认成 `i32`。可用后缀明确类型：`2u64`。  
大数字可用下划线：`1_000_000`。

## 算术运算

整数支持 `+ - * / %` 等。**不同类型不能直接混算**，需要类型一致或显式转换。
