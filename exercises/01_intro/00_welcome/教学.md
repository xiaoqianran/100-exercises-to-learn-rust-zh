# 入门 / 欢迎

> 状态：完整 · 上游练习：`01_intro/00_welcome` · crate：`welcome_00`

## 1. 本题目标

熟悉课程工作流：阅读注释、修改代码、运行测试，确认环境可用。

章节主题：从零认识 Rust 与课程工作流

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 修改 `greeting` 函数返回值，把 `__` 换成正确文案，使返回值为 `I'm ready to learn Rust!`。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p welcome_00
```

或在本练习目录执行：

```bash
cd exercises/01_intro/00_welcome
cargo test
```

只看失败测试：

```bash
cargo test -p welcome_00 -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p welcome_00 --open
```

## 4. 期望结果 / 通过标准

测试 `test_welcome` 通过，断言 greeting() 等于指定英文句子。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 字符串字面量用双引号 `"..."`。
- 注意大小写、标点与空格必须与测试完全一致。
- 不要修改 `#[cfg(test)]` 下的测试代码。

## 6. 常见错误

- 改了测试而不是实现。
- 拼写错误（如 Rust 大小写）。
- 返回了中文或其他句子。
