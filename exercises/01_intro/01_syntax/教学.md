# 入门 / 语法

> 状态：完整 · 上游练习：`01_intro/01_syntax` · crate：`syntax`

## 1. 本题目标

学会给函数参数标注类型，理解函数签名。

章节主题：从零认识 Rust 与课程工作流

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 为 `compute(a, b)` 的参数补上类型，使其与返回类型 `u32` 一致。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p syntax
```

或在本练习目录执行：

```bash
cd exercises/01_intro/01_syntax
cargo test
```

只看失败测试：

```bash
cargo test -p syntax -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p syntax --open
```

## 4. 期望结果 / 通过标准

`compute(1, 2)` 返回 `5`（即 1 + 2*2）。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 语法：`fn compute(a: u32, b: u32) -> u32`。
- 先读编译器报错，它会提示缺少类型。
- 函数体 `a + b * 2` 不要改。

## 6. 常见错误

- 参数类型写成了其他整数类型导致不匹配。
- 改了函数体而不是签名。
