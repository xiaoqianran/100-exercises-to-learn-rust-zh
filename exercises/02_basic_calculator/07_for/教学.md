# 基础计算器 / 循环 for

> 状态：完整 · 上游练习：`02_basic_calculator/07_for` · crate：`for_`

## 1. 本题目标

用 `for` 与范围语法重写阶乘。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 用 `for i in 1..=n` 累乘。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p for_
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/07_for
cargo test
```

只看失败测试：

```bash
cargo test -p for_ -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p for_ --open
```

## 4. 期望结果 / 通过标准

同上测试通过。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- `1..=n` 是包含上界的范围；`n=0` 时范围为空。

## 6. 常见错误

- 写成 `1..n` 少乘 n。
