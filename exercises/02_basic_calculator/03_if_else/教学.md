# 基础计算器 / 分支 if/else

> 状态：完整 · 上游练习：`02_basic_calculator/03_if_else` · crate：`if_else`

## 1. 本题目标

使用 `if/else if/else` 实现多分支逻辑。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 实现 `magic_number`：偶数返回 12；否则能被 3 整除返回 13；否则 17。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p if_else
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/03_if_else
cargo test
```

只看失败测试：

```bash
cargo test -p if_else -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p if_else --open
```

## 4. 期望结果 / 通过标准

1→17，2→12，6→12，9→13，233→17。注意偶数优先于「能被 3 整除」。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- `n % 2 == 0` 判断偶数。
- 6 既是偶数又能被 3 整除，应返回 12。

## 6. 常见错误

- 先判断 `% 3` 导致 6 返回 13。
