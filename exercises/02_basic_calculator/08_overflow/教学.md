# 基础计算器 / 溢出与下溢

> 状态：完整 · 上游练习：`02_basic_calculator/08_overflow` · crate：`overflow`

## 1. 本题目标

理解 debug 下默认溢出检查，并在仓库根 `Cargo.toml` 配置 wrap 行为。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 在**仓库根** `Cargo.toml` 增加 profile 配置，使本包在 dev 下溢出环绕（wrap），而不是 panic。按题目注释与 Cargo 文档操作。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p overflow
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/08_overflow
cargo test
```

只看失败测试：

```bash
cargo test -p overflow -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p overflow --open
```

## 4. 期望结果 / 通过标准

`factorial(20)` 等于 `2_192_834_560`（u32 环绕结果），小值阶乘仍正确。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 配置写在仓库根，不是练习目录的 Cargo.toml。
- 参考：`[profile.dev.package.overflow]` 或 workspace 已有类似 `copy` 包的写法。
- 包名以本练习 `Cargo.toml` 的 `name` 为准（`overflow`）。

## 6. 常见错误

- 改了练习目录 Cargo.toml；包名写错。
