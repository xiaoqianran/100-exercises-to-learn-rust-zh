# 基础计算器 / 饱和运算

> 状态：完整 · 上游练习：`02_basic_calculator/09_saturating` · crate：`saturating`

## 1. 本题目标

使用饱和乘法，溢出时夹在类型最大值而不是环绕。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 把 `result *= i` 改为饱和乘法（如 `result = result.saturating_mul(i)`）。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p saturating
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/09_saturating
cargo test
```

只看失败测试：

```bash
cargo test -p saturating -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p saturating --open
```

## 4. 期望结果 / 通过标准

`factorial(20) == u32::MAX`，小值仍正确。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 查阅 `u32::saturating_mul`。

## 6. 常见错误

- 仍用普通 `*` 导致 wrap 或 panic。
