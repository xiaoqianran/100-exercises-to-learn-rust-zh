# 基础计算器 / 恐慌 panic

> 状态：完整 · 上游练习：`02_basic_calculator/04_panics` · crate：`panics`

## 1. 本题目标

在非法输入时用 `panic!` 主动失败，并带上自定义消息。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 当 `time_elapsed == 0` 时 panic，消息必须为：`The journey took no time at all. That's impossible!`

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p panics
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/04_panics
cargo test
```

只看失败测试：

```bash
cargo test -p panics -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p panics --open
```

## 4. 期望结果 / 通过标准

正常路径仍返回速度；零时间路径触发 `#[should_panic(expected = ...)]`。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- `if time_elapsed == 0 { panic!("The journey took no time at all. That's impossible!"); }`
- 消息字符串必须完全一致。

## 6. 常见错误

- 消息多/少标点；用了 `assert!` 却消息不对。
