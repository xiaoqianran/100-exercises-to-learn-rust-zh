# 基础计算器 / 整数类型

> 状态：完整 · 上游练习：`02_basic_calculator/01_integers` · crate：`integers`

## 1. 本题目标

理解不同整数类型不能直接混算，需要类型一致。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 修正 `multiplier` 的类型或转换方式，使 `a + b * multiplier` 能编译并通过测试。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p integers
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/01_integers
cargo test
```

只看失败测试：

```bash
cargo test -p integers -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p integers --open
```

## 4. 期望结果 / 通过标准

`compute(1, 2)` 等于 `9`。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- `a`、`b` 是 `u32`，`multiplier` 写成 `u8` 会类型错误。
- 可把 `multiplier` 改成 `u32`，或使用 `as u32` / `u32::from(...)`。

- 只改测试；忽略编译错误信息。
