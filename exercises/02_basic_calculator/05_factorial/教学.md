# 基础计算器 / 阶乘（递归）

> 状态：完整 · 上游练习：`02_basic_calculator/05_factorial` · crate：`factorial`

## 1. 本题目标

用递归实现阶乘（本章此时尚未教循环）。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 定义 `fn factorial(n: u32) -> u32`，`0! = 1`，`n! = n * (n-1)!`。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p factorial
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/05_factorial
cargo test
```

只看失败测试：

```bash
cargo test -p factorial -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p factorial --open
```

## 4. 期望结果 / 通过标准

0→1，1→1，2→2，5→120。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 递归基：`if n == 0 { return 1; }`
- 递归步：`n * factorial(n - 1)`

## 6. 常见错误

- 漏掉 0 的情况；使用了循环（本题要求递归）。
