# 基础计算器 / as 类型转换

> 状态：完整 · 上游练习：`02_basic_calculator/10_as_casting` · crate：`as_cast`

## 1. 本题目标

理解 `as` 转换：拓宽、截断、bool 到整数。

章节主题：整数、变量、分支、循环与溢出

## 4. 期望结果 / 通过标准

u16→u32 为 47；`255 as i8` 的等价真 i8；`true as u8` 为 1。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 拓宽通常数值不变：`47u32`。
- 255 转 i8 在二进制上是 -1（two's complement）。
- `true as u8 == 1`，`false as u8 == 0`。

## 6. 常见错误

- u8_to_i8 直接复制 `255 as i8` 字面量投机取巧（题目不鼓励）。
