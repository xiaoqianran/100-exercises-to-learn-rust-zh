# 基础计算器 / 变量

> 状态：完整 · 上游练习：`02_basic_calculator/02_variables` · crate：`variables`

## 1. 本题目标

用 `let` 定义变量，计算平均速度。

章节主题：整数、变量、分支、循环与溢出

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 在 `speed` 中定义 `distance`（通常为 `end - start`）。

⚠️ **不要修改测试模块**（`#[cfg(test)]` 下的代码），除非题目明确要求。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p variables
```

或在本练习目录执行：

```bash
cd exercises/02_basic_calculator/02_variables
cargo test
```

只看失败测试：

```bash
cargo test -p variables -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p variables --open
```

## 4. 期望结果 / 通过标准

三个 case：`(0,10,10)->1`，`(10,30,10)->2`，`(10,31,10)->2`（整数除法截断）。

终端中应看到类似：

```text
test result: ok. X passed; 0 failed; ...
```

## 5. 思路提示

- 类型可推断，也可写 `let distance = end - start;`。
- 整数除法会向下取整。

## 6. 常见错误

- 用了错误的距离公式；忘记 `let`。
