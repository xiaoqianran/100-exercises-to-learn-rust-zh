## 1. 本题目标

用 `Status` 枚举替代字符串状态。

## 2. 你需要改哪里

## 5. 思路提示

- enum Status { ToDo, InProgress, Done }
- 测试用结构体字面量直接赋 Status，new 可能需改成接收 Status
- 若 new 仍收 String 需映射；以测试为准——测试未调用 new，主要改字段类型与 derive



## 6. 常见错误

- Status 未 PartialEq；变体名写错（To-Do vs ToDo）。
