> 状态：完整 · 上游：`05_ticket_v2/04_if_let` · crate：`if_let`

## 1. 本题目标

仅 Circle 有 radius；其他 panic。

## 2. 你需要改哪里

- 主文件见练习目录 `src/`
- 用 if let 或 let-else 实现 `radius`。

## 3. 如何运行

```bash
cargo test -p if_let
```

```bash
cd exercises/05_ticket_v2/04_if_let && cargo test
```

binary 练习可用：

```bash
cargo run -p if_let
```

## 4. 期望结果

Circle 返回半径；Square/Rectangle panic。

## 5. 思路提示

- if let Shape::Circle { radius } = self { *radius } else { panic!() }

- 用 match 也可以但题目希望 if let/let-else。
