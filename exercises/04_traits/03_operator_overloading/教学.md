# 特征 Traits / 运算符重载

> 状态：完整 · 上游练习：`04_traits/03_operator_overloading` · crate：`overloading`

## 1. 本题目标

为本地类型实现 `PartialEq`，支持 `==` / `!=`。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 补全 `impl PartialEq for Ticket`：比较三个字段。

## 3. 如何运行

```bash
cargo test -p overloading
```

或：

```bash
cd exercises/04_traits/03_operator_overloading
cargo test
```

```bash
cargo test -p overloading -- --nocapture
```

## 4. 期望结果 / 通过标准

字段全相同则相等，任一不同则不等。

## 5. 思路提示

- `fn eq(&self, other: &Self) -> bool`
- 比较 title、description、status
- 实现 PartialEq 后 `!=` 有默认实现



## 6. 常见错误

- 空 impl；漏比较字段。
