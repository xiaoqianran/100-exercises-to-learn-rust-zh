# 特征 Traits / Trait

> 状态：完整 · 上游练习：`04_traits/01_trait` · crate：`trait_`

## 1. 本题目标

自定义 trait 并为多种类型实现。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 定义 `IsEven`（方法 `is_even`），为 `u32` 与 `i32` 实现。

## 4. 期望结果 / 通过标准

偶数 true、奇数 false；含 0 与负数用例。

## 5. 思路提示

- `trait IsEven { fn is_even(&self) -> bool; }`
- `impl IsEven for u32 { ... self % 2 == 0 }`
- i32 同样用取模；注意负数：`(-1) % 2` 在 Rust 为 -1，更稳妥可用 `self & 1 == 0` 或 `self % 2 == 0`（-2 为 true）
- 测试期望 -1 不是偶数，0 是偶数



## 6. 常见错误

- 只实现了一个类型；`% 2` 对负数处理不当。
