# 特征 Traits / From

> 状态：完整 · 上游练习：`04_traits/09_from` · crate：`from`

## 1. 本题目标

实现 `From<u32> for WrappingU32`，从而支持 `from` 与 `into`。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 编写 `impl From<u32> for WrappingU32`。

## 3. 如何运行

```bash
cargo test -p from
```

或：

```bash
cd exercises/04_traits/09_from
cargo test
```

```bash
cargo test -p from -- --nocapture
```

## 4. 期望结果 / 通过标准

`example` 中两行转换都能编译。

## 5. 思路提示

- `impl From<u32> for WrappingU32 { fn from(value: u32) -> Self { Self { value } } }`
- `Into` 有基于 From 的空白实现



## 6. 常见错误

- 实现成了 Into 却签名不对；字段私有需在 impl 内构造。
