# 特征 Traits / 孤儿规则

> 状态：完整 · 上游练习：`04_traits/02_orphan_rule` · crate：`orphan`

## 1. 本题目标

认识孤儿规则：不能为外部类型实现外部 trait。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 阅读编译错误，然后**删除**违规的 `impl PartialEq for u32`，进入下一题。

## 3. 如何运行

```bash
cargo test -p orphan
```

或：

```bash
cd exercises/04_traits/02_orphan_rule
cargo test
```

```bash
cargo test -p orphan -- --nocapture
```

## 4. 期望结果 / 通过标准

删除后 `cargo test -p orphan`（或 check）不再因孤儿规则失败。

## 5. 思路提示

- 规则：impl 时 trait 或类型至少有一个在当前 crate 定义
- 本题是刻意的反例，正确做法是删掉代码
