# 特征 Traits / 关联类型 vs 泛型

> 状态：完整 · 上游练习：`04_traits/10_assoc_vs_generic` · crate：`assoc_vs_generic`

## 1. 本题目标

定义 `Power` trait，使 `u32` 能以不同指数类型求幂。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 实现足够让 `2u32.power(3u16|3u32|&3u32)` 得到 8。可用泛型参数或分别 impl。

## 3. 如何运行

```bash
cargo test -p assoc_vs_generic
```

或：

```bash
cd exercises/04_traits/10_assoc_vs_generic
cargo test
```

```bash
cargo test -p assoc_vs_generic -- --nocapture
```

## 4. 期望结果 / 通过标准

三个测试通过。

## 5. 思路提示

- 可用 `trait Power<RHS=Self> { type Output; fn power(self, n: RHS) -> Self::Output; }`
- 或对 u16/u32/&u32 分别 `impl Power<u16> for u32` 等
- 简单循环累乘即可



## 6. 常见错误

- 只实现一种 RHS；返回类型不对。
