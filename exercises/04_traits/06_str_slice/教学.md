# 特征 Traits / 字符串切片

> 状态：完整 · 上游练习：`04_traits/06_str_slice` · crate：`str_slice`

## 1. 本题目标

getter 返回 `&str` 而非 `&String`（更通用）。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 修改三个 accessor 返回类型为 `&str`。

## 3. 如何运行

```bash
cargo test -p str_slice
```

或：

```bash
cd exercises/04_traits/06_str_slice
cargo test
```

```bash
cargo test -p str_slice -- --nocapture
```

## 4. 期望结果 / 通过标准

`TypeId` 断言返回的是 `str`（通过 `&str` 解引用强制）。

## 5. 思路提示

- `pub fn title(&self) -> &str { &self.title }`
- `String` 可解引用为 `str`（Deref）



## 6. 常见错误

- 仍返回 `&String`。
