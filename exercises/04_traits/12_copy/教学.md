# 特征 Traits / Copy

> 状态：完整 · 上游练习：`04_traits/12_copy` · crate：`copy`

## 1. 本题目标

为包装类型实现加法与相等，并支持 Copy 语义相关推导。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 实现使 `x+y+y+z` 通过的 trait（`Add`、`PartialEq`/`Eq`，通常还要 `Copy`+`Clone`）。不可改测试。

## 4. 期望结果 / 通过标准

运算结果等于 `WrappingU32::new(103)`。

## 5. 思路提示

- 派生 `Copy, Clone`（仅含 u32 可以）
- `impl Add for WrappingU32` 做 wrapping 或普通加（42+31+31+MAX 按测试=103，说明是 wrapping 加法：溢出环绕）
- 计算：42+31=73，+31=104，+u32::MAX wrapping → 103 是的（104-1 wrapping with MAX）
- 需要 `PartialEq`（assert_eq!）

仓库根 `Cargo.toml` 已有 `[profile.dev.package.copy] overflow-checks = true`，注意溢出行为。


## 6. 常见错误

- 用 checked 而非 wrapping；忘记 Copy 导致多次使用问题；缺 Debug 时 assert_eq 可能也要 Debug——测试用 assert_eq 需要 PartialEq+Debug
