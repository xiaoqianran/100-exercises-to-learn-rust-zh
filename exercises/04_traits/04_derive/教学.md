# 特征 Traits / 派生宏 derive

> 状态：完整 · 上游练习：`04_traits/04_derive` · crate：`derives`

## 1. 本题目标

用 `#[derive(...)]` 自动生成 trait 实现。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 为 `Ticket` 补上缺失的可 derive trait（本题是 `Debug`，已有 `PartialEq`）。

## 3. 如何运行

```bash
cargo test -p derives
```

或：

```bash
cd exercises/04_traits/04_derive
cargo test
```

```bash
cargo test -p derives -- --nocapture
```

## 4. 期望结果 / 通过标准

`assert_eq!` / `assert_ne!` 能编译并运行通过。

## 5. 思路提示

- `#[derive(PartialEq, Debug)]`
- `assert_eq!` 失败时要打印值，需要 Debug



## 6. 常见错误

- 手写 Debug 过繁；漏 derive Debug。
