# 特征 Traits / Drop

> 状态：完整 · 上游练习：`04_traits/13_drop` · crate：`drop`

## 1. 本题目标

实现 Drop bomb：未拆除时 drop 会 panic。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 实现 `DropBomb::new` / `defuse`，并 `impl Drop`。

## 3. 如何运行

```bash
cargo test -p drop
```

或：

```bash
cd exercises/04_traits/13_drop
cargo test
```

```bash
cargo test -p drop -- --nocapture
```

## 4. 期望结果 / 通过标准

未 defuse 时 drop panic；defuse 后正常 drop。

## 5. 思路提示

- 结构体含 `defused: bool`
- `impl Drop for DropBomb { fn drop(&mut self) { if !self.defused { panic!() } } }`
- `defuse(&mut self)` 设为 true



## 6. 常见错误

- Drop::drop 签名不对；defuse 后仍 panic。
