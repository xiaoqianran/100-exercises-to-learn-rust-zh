# 特征 Traits / Clone

> 状态：完整 · 上游练习：`04_traits/11_clone` · crate：`clone`

## 1. 本题目标

在需要「既保留原值又消费」时使用 Clone。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 为相关类型实现/派生 Clone，并在 `summary` 里在 move 前 clone。

## 3. 如何运行

```bash
cargo test -p clone
```

或：

```bash
cd exercises/04_traits/11_clone
cargo test
```

```bash
cargo test -p clone -- --nocapture
```

## 4. 期望结果 / 通过标准

`summary` 函数编译通过。

## 5. 思路提示

- `#[derive(Clone)]` 在 Ticket/Summary 上
- `(ticket.clone(), ticket.summary())` 或先 summary 再组——注意 summary 吃掉 self
- 正确：`let s = ticket.clone().summary(); (ticket, s)` 或先 clone 再分别用



## 6. 常见错误

- clone 时机不对仍 move 两次。
