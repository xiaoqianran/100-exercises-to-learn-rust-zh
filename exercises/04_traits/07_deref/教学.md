# 特征 Traits / Deref

> 状态：完整 · 上游练习：`04_traits/07_deref` · crate：`deref`

## 1. 本题目标

返回前去掉首尾空白；方法在 `str` 上（经 Deref 可从 String 调用）。

章节主题：Trait、运算符重载、From/Clone/Copy/Drop

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 实现 `title`/`description` 返回 trim 后的 `&str`。

## 3. 如何运行

```bash
cargo test -p deref
```

或：

```bash
cd exercises/04_traits/07_deref
cargo test
```

```bash
cargo test -p deref -- --nocapture
```

## 4. 期望结果 / 通过标准

带空格的 Ticket 读出规范化字符串。

## 5. 思路提示

- `self.title.trim()` 来自 `str::trim`
- 因 `String: Deref<Target=str>` 可直接在 String 上调用



## 6. 常见错误

- 自己手写跳过空白易错；trim_matches 用法不当。
