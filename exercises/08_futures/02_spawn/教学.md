# 异步 Futures / spawn 并发

> 状态：完整 · `08_futures/02_spawn` · crate：`spawn`

## 1. 本题目标

两 listener 并发，连接也并发处理。

## 2. 你需要改哪里

- tokio::spawn 每个连接；可用 select!/join 跑两个 accept 循环。

## 3. 如何运行

```bash
cargo test -p spawn
```

```bash
cd exercises/08_futures/02_spawn && cargo test
```

## 4. 期望结果

两端口并发请求均 echo。

## 5. 思路提示

- spawn(async move { loop { accept... } })
- 或 join! 两个 serve 任务



## 6. 常见错误

- 串行 accept 导致超时。
