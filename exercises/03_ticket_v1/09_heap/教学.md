# 工单 v1 / 堆

> 状态：完整 · 上游练习：`03_ticket_v1/09_heap` · crate：`heap`

## 1. 本题目标

理解 `String` 在栈上是「指针+长度+容量」，动态字符在堆上。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 填入 `String` 与 `Ticket` 的 `size_of`（栈上元数据大小）。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p heap
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/09_heap
cargo test
```

查看详细输出：

```bash
cargo test -p heap -- --nocapture
```

## 4. 期望结果 / 通过标准

两处断言通过。在 64 位目标上通常：`String` 为 24，`Ticket` 为 3*24=72。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 栈上 `String` = pointer + length + capacity，各 `usize`（64 位下各 8 字节）→ 24
- `Ticket` 含 3 个 `String` → 72（本题直觉答案正确）
- 可用 `std::mem::size_of::<String>()` 在本机确认



## 6. 常见错误

- 误以为 size_of 会算上堆数据长度。
