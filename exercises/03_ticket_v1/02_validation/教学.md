# 工单 v1 / 校验

> 状态：完整 · 上游练习：`03_ticket_v1/02_validation` · crate：`validation`

## 1. 本题目标

在 `Ticket::new` 中强制校验 title/description/status，不合法则 panic。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 实现 `new`：空标题/空描述、超长、非法 status 时按测试 `expected` 消息 panic；合法则返回 `Ticket`。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p validation
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/02_validation
cargo test
```

查看详细输出：

```bash
cargo test -p validation -- --nocapture
```

## 4. 期望结果 / 通过标准

全部 `should_panic` 与正常路径测试通过。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 空串：`title.is_empty()` / `description.is_empty()`
- 长度：`title.len() > 50`、`description.len() > 500`（按**字节**）
- status 仅允许：`To-Do` / `In Progress` / `Done`
- panic 消息必须与测试完全一致（含反引号）
- 可用 `common` crate 的辅助字符串（测试已 use）



## 6. 常见错误

- panic 文案差一个字符；用字符数而非字节数；漏检 status。
