# 工单 v1 / 结构体

> 状态：完整 · 上游练习：`03_ticket_v1/01_struct` · crate：`struct_`

## 1. 本题目标

定义结构体 `Order` 并实现方法 `is_available`。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 在 `src/lib.rs` 中定义字段 `price: u32`、`quantity: u32`，以及方法 `is_available(&self) -> bool`（quantity > 0 为 true）。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p struct_
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/01_struct
cargo test
```

查看详细输出：

```bash
cargo test -p struct_ -- --nocapture
```

## 4. 期望结果 / 通过标准

quantity>0 时 `is_available()` 为 true；为 0 时为 false。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 结构体语法：`struct Order { price: u32, quantity: u32 }`
- 方法写在 `impl Order { ... }` 中
- 方法签名建议：`fn is_available(&self) -> bool`



## 6. 常见错误

- 字段类型用错；忘记 `impl`；方法拿走了 `self` 导致后续难用（本题测试较简单但仍建议用 `&self`）。
