# 工单 v1 / Setter

> 状态：完整 · 上游练习：`03_ticket_v1/07_setters` · crate：`setters`

## 1. 本题目标

实现 `&mut self` 的 setter，并复用与 `new` 相同的校验规则。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 添加 `set_title` / `set_description` / `set_status`；非法输入 panic 消息与 `new` 一致。建议抽取私有校验函数。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p setters
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/07_setters
cargo test
```

查看详细输出：

```bash
cargo test -p setters -- --nocapture
```

## 4. 期望结果 / 通过标准

正常修改字段通过；各非法 setter 触发对应 `should_panic`。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 签名：`pub fn set_title(&mut self, new_title: String)`
- 先 validate 再赋值
- 可写 `fn validate_title(title: &str) { ... }`



## 6. 常见错误

- setter 未校验；消息不一致；接收者不是 `&mut self`。
