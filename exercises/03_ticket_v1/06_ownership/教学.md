# 工单 v1 / 所有权

> 状态：完整 · 上游练习：`03_ticket_v1/06_ownership` · crate：`ownership`

## 1. 本题目标

访问器改为借用 `&self`，避免拿走所有权导致无法连续调用。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 把 `title`/`description`/`status` 从 `self` 改为 `&self`，返回引用（如 `&String` 或 `&str`）。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p ownership
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/06_ownership
cargo test
```

查看详细输出：

```bash
cargo test -p ownership -- --nocapture
```

## 4. 期望结果 / 通过标准

同一 `ticket` 上连续调用三个 getter 且断言通过。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 签名示例：`pub fn title(&self) -> &String { &self.title }`
- 理解：`self` 会 move；`&self` 只读借用



## 6. 常见错误

- 仍用 `self` 导致第二次调用编译失败；返回类型与 `&` 不匹配。
