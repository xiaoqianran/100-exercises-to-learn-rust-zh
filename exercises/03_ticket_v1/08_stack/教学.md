## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p stack
```

或在本练习目录执行：

```bash
cd exercises/03_ticket_v1/08_stack
cargo test
```

只看失败测试：

```bash
cargo test -p stack -- --nocapture
```

生成文档（部分题有文档注释时有用）：

```bash
cargo doc -p stack --open
```
