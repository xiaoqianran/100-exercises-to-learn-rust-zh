## 1. 本题目标

用 `std::mem::size_of` 理解类型在栈上占用的字节数。

章节主题：结构体、模块、所有权与内存

- 把 `todo!()` 换成 `u16`/`i32`/`bool` 的正确大小。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 4. 期望结果 / 通过标准

三处断言成立（常见平台：2、4、1）。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- `size_of::<u16>() == 2`
- `size_of::<i32>() == 4`
- `size_of::<bool>() == 1`
- 这些与是否 32/64 位平台无关（固定宽度整数）



## 6. 常见错误

- 把位数当成字节数（如 u16 写成 16）。
