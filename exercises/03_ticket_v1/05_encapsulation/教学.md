# 工单 v1 / 封装

> 状态：完整 · 上游练习：`03_ticket_v1/05_encapsulation` · crate：`encapsulation`

## 1. 本题目标

在字段私有前提下提供公开访问器（getter）。

章节主题：结构体、模块、所有权与内存

## 2. 你需要改哪里

- 主文件：[`src/lib.rs`](./src/lib.rs)
- 包清单：[`Cargo.toml`](./Cargo.toml)
- 为 `Ticket` 增加 `title` / `description` / `status` 三个公开方法返回字段内容。

⚠️ 除非题目**明确**要求，否则不要改测试；本题特殊说明见「思路提示」。

## 3. 如何运行

在**仓库根目录**执行（推荐）：

```bash
cargo test -p encapsulation
```

或在本练习目录：

```bash
cd exercises/03_ticket_v1/05_encapsulation
cargo test
```

查看详细输出：

```bash
cargo test -p encapsulation -- --nocapture
```

## 4. 期望结果 / 通过标准

三个测试断言 getter 返回正确字符串。

终端应出现：

```text
test result: ok. ...
```

## 5. 思路提示

- 本题阶段可能用 `fn title(self) -> String { self.title }` 也能过测试
- 下一题会改为 `&self` 借用，可提前使用 `fn title(&self) -> &String { &self.title }`



## 6. 常见错误

- 方法未 `pub`；方法名与测试不一致。
